# Design Registry &amp; Style Architecture &bull; MetricBrainCliff

## 1. Brand Identity &amp; Aesthetic
- **Brand Name:** MetricBrainCliff
- **Category / Niche:** Cognitive Neuroscience &bull; Quantitative Learning Institute &bull; Education
- **Design Philosophy:** Intellectual Oxford navy, analytical cyan data metrics, crisp scholarship ivory, mathematical rigor, and evidence-based neuro-pedagogy.

## 2. Color Palette &amp; Design Tokens
- `--color-bg`: `#F8FAFC` (Crisp Academic Alabaster)
- `--color-surface`: `#FFFFFF` (Pure Studio White)
- `--color-surface-subtle`: `#EEF2F6` (Soft Telemetry Slate)
- `--color-border`: `#DDE3EA` (Scholarly Border Grey)
- `--color-slate-900`: `#0B132B` (Obsidian Deep Navy)
- `--color-slate-800`: `#1C2541` (Oxford Scholar Navy)
- `--color-accent`: `#1D4ED8` (Cognitive Cobalt Royal)
- `--color-accent-light`: `#3B82F6` (Electric Azure Highlight)
- `--color-cyan`: `#0284C7` (Analytical Data Cyan)
- `--color-gold`: `#D97706` (Scholarly Amber Bronze)

## 3. Typography Hierarchy
- **Serif Display:** `'Cormorant Garamond', Garamond, Georgia, serif` &mdash; Institutional titles, academic branding, classical scholarship.
- **Sans Body:** `'Plus Jakarta Sans', sans-serif` &mdash; Clean, balanced contemporary legibility across body text.
- **Monospace Technical:** `'JetBrains Mono', monospace` &mdash; Telemetry metrics, mathematical equations, retention indices, and badges.

## 4. UI Components &amp; Layout Systems
- **Header:** Sticky with `backdrop-filter: blur(12px)`, synchronized mobile drawer.
- **Interactive Tool:** Cognitive Retention Cliff Calculator with dynamic Ebbinghaus decay simulation.
- **Cards:** Clean border elevation with subtle hover transform and image zoom transitions.
- **Accordions:** Smooth toggle FAQs for admissions guidance and research monographs.
